## 二、H1~H7 逐项落地情况

### H1 · 空中维度：数据与规则 ✅

- `GameData.AIR_RULES` 一张表管住「谁能打空、谁在天上」（**不给 17 个单位各加字段**）。
  缺省 = 地面单位只能打地面，新增单位不用写任何东西。
- 星际 1 的四把对空枪：陆战队员 / 刺蛇 / 龙骑士 / 执政官。
- 三族空军：幽灵战机（人）/ 飞龙（虫）/ 侦察机（神）。
- 三族防空建筑：导弹塔、孢子菌落**只对空**；光子炮台**对空 + 对地**。

**核验**：`tests/Air.gd` 第一组 —— 不存在「空中单位打不到地面」这类死配置。

### H2 · 建筑开火子系统 + 对空/对地索敌 ✅（方案里标为最高风险项）

- `Building` 补 `cooldown` / `attack_timer`，`World._update_buildings()` 驱动开火，
  伤害复用 `compute_damage()`、弹道复用现有 `projectiles`。
- 索敌过滤是空/地的**唯一闸门**：`find_nearest_enemy(..., attacker)` 按 `can_hit` 过滤；
  已有目标处再补一道 `if not u.can_hit(target): target = null` ——
  少了这道，单位会「有目标但不攻击也不移动」，追着飞机绕地图跑。

**核验**：`tests/Air.gd` 第二组 —— 地面近战打不到空中 / 对空单位能打到 /
防空建筑能打到 / 空中单位不会被地面近战锁住。

### H3 · 空中移动、碰撞分层与渲染 ✅

- 飞行单位**直线移动不寻路**；忽略岩石与建筑占位，只 clamp 到地图内。
- `_separate()` 分层：空↔空互推（保队形）、**空↔地不互推**
  （否则飞机会把采矿农民挤开，而农民够不到它）。
- 溅射只影响同一层。
- 渲染分两遍：地面在前、空中在后；飞行单位本体上浮 + 影子偏移缩小 + 机翼。

**核验**：截图 `17_air_units.png` / `18_anti_air.png`。

### H4 · 地形高低差：网格与寻路 ✅

- `Grid` 加 `elevation`；地图生成器产出高地平台 + 坡道。
- **通行性一律走 `Grid.can_step()`**：同层随便走，跨层只有至少一格是坡道才放行。
  `nearest_free_world` / `scatter_slot` / A* 邻接 / `_clear_line` 全走它。
- `_clear_line` 必须**逐格**走 —— 只判两端会让拉绳平滑把路径拉成「爬墙」。
- 建造规则：不能跨悬崖，也不能建在坡道上（坡道判定必须排在「跨悬崖」之前）。

**核验**：`tests/Terrain.gd` 第一组 —— 低地单位绕行坡道 / 飞行单位直线穿越 /
跨层建造被拒 / 低地看不到高地上的敌人。

### H5 · 地形高低差：战斗加成与渲染 ✅

- 高地打低地：视野 +1 格、射程 +1 格（`HIGH_GROUND_SIGHT_BONUS` / `RANGE_BONUS = 24`）。
- 低地打高地：**固定 30% 打空**（`World.UPHILL_MISS`），**只对地面对地面生效** ——
  飞行单位无论当射手还是目标一律不吃。
- 掷骰位置在 `_impact()` 里、且在 `target == null` 之前
  （放开火时画面像「一半的兵在哑火」；放判空之后则变相提高高地收益）。
- 加成走**标记 + 读取时叠加**：`World._refresh_terrain_flags()` 刷 `Unit.on_high_ground`，
  `sight()` / `attack_range()` 只读标记。
- AI 会把空闲的作战单位摆到自家附近高地上驻防（`AI_HOLD_RADIUS = 520`，6 秒节流）。

**核验**：`tests/Terrain.gd` 第二/三组 + 截图 `19_elevation.png`。

### H6 · 虫族菌毯 ✅

- 菌毯 =「**已完工**」虫族建筑的半径并集，缓存进 `Grid.creep`；
  渲染与规则判定读**同一份数据**。
- 两个豁免（缺一个游戏静默坏掉）：`hive`（它自己就是菌毯源，要求它建在菌毯上
  等于「先有鸡」）、`gas_building`（只能压在气矿上，气矿位置是地图定的、
  可能整片不在菌毯内 —— 不豁免 AI 永远开不出气）。
- 只有虫族**地面**单位吃 +30% 移速（人神无效、空军不吃）。

**核验**：`tests/Creep.gd` 19 项 + 截图 `20_creep.png`。

### H7 · 对局外围 ✅

| 能力 | 实现要点 |
|---|---|
| 地图三张 | `open` 开阔平原 / `plateau` 双坡道高地（默认）/ `river` 中间河道。**三张都对称** —— 非对称在 1v1 里等于开局定胜负 |
| 游戏速度 1×/1.5×/2× | 倍率**只乘在喂给 `world.step()` 的 delta 上**，不碰任何单位数值 → 2× 与 1× 平衡完全一致 |
| 顶栏暂停 | 暂停**整段跳过 `world.step()`**，不是把 delta 置 0（置 0 会让世界里的计时器每帧重置） |
| 帮助页音量滑块 | 命中判定排在「点任意处关闭面板」**之前**，否则一按就关、滑块永远拖不动 |

**核验**：`tests/Touch.gd` 第 14 组 18 条 + `tests/Terrain.gd` 第四组 9 条
+ 截图 `21_river.png` / `22_menu.png` / `06_help.png`。

## 四、诚实的缺口（没做的部分）

1. **AI 进攻时不会主动利用高地** —— 只做了防守驻防，进攻路线仍是直推。
2. **战略级科技对抗未覆盖** —— `bal.gd` 的玩家脚本全文检索
   `research` / `upgrade` / `cmd_ability` **命中数为 0**，
   也就是说平衡对局里双方都不升科技、不放技能。
3. **存档 / 重播 / 多人联机** —— 方案第六节已明确不做。

## 五、3 分钟验收清单

装 release 包，按顺序点一遍：

1. **开局菜单** → 切到「地图：中间河道」「速度：2×」→ 开始战斗。
   进局后地图中间应有一条**青色的深渊带**，上面**三座木色桥**。
2. **顶栏** → 点「速度」应在 1× / 1.5× / 2× 之间循环；点「暂停」画面压暗并显示「已 暂 停」。
3. **操作说明**（顶栏）→ 面板底部拖音量滑块，最左是静音；**点滑块不会关面板**，
   点别处才关。
4. 开局给的高地上站几个兵 → 选中后**看射程圈**应比在低地时大一圈；
   把兵拉下低地打高地，应能看到**明显打空**（约三成）。
5. 造一个虫族建筑 → 在菌毯外应放不下去（轮廓变红）；虫族地面兵站菌毯上明显更快。
6. 造一架**幽灵战机** → 让它飞过悬崖，应直接穿过；地面的跳虫/狂热者**不会追它**。

任何一步不对，把现象告诉我即可 —— 上面每条都有对应的测试套件可以立刻定位。
