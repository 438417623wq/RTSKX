# 第十六轮 · M6 诱捕网落地报告

> 承接第十五轮（M5 施法系统）。M5 建好了「施法」的三层地基 ——
> 区域 / 状态效果 / 施法者 —— 但**只铺了三种「持久区域 + dot」形态的法术**。

> **「一次性施法」**：它在放下去的那一瞬间抓人，效果随后跟着单位走。

## 二、本轮改的三个真问题（都不报错）

### 2.1 `Unit.cooldown_time()` 的提前 `return`

原写法：

```gdscript
if mode == "sieged":
    return float(GameData.get_ability("siege").get("attack_cooldown", c))
if buffs.has("stim"):
    c *= ...
return c
```

把「诱捕网降射速」的 `c *= atk_cd_mult()` 加在这个 `return` **之后**，
代码看着像加上了，实际上**永远轮不到攻城模式**。
症状是「展开的攻城坦克完全不受诱捕网影响」——
普通兵种的测试全绿，只有专门测「展开状态」的那一条会红。

改成**赋值 + 最后统一乘**（`c = <siege 冷却>` 而不是 `return`），
对 siege 之外的单位行为逐点不变。阳性对照 `C17` 专门守这一条。

### 2.2 客户端重建效果参数时漏了 `slow_mult`

`Net.apply_snapshot()` 解效果时只填 `id / kind / remain / duration`。
M5 时 `slow` 没有产出方，这条路径一直是空的，所以没暴露；
M6 的诱捕网是第一个真正走到它的法术。

⚠️ 症状很隐蔽：客户端**不跑 `step()`**（权威模拟只在主机），
位置由快照纠正，所以**连错位都看不出来** —— 只是客户端的表现层
（速度 / 动画 / 未来的剩余时间条）全是错的。

修法：参数从本地 `GameData.SPELLS` 按 `id` 重建（和法术区域半径同一条纪律）。
**`dps` / `spread_radius` 故意不重建** —— 伤害是主机权威的，
客户端拿到 `dps` 的话，将来一旦有人在客户端跑 `step()` 就会双倍结算。

### 2.3 「持久区域」的测试断言恒真

写「诱捕网 vs 持久区域」的镜像对照时，持久区域那半边是：

```gdscript
w2.cmd_ability([df], "dark_swarm", spot2)
_report("虫群落下时圈内单位被标记（前提）", out.has_effect("dark_swarm"), ...)
```

—— **施法后没有推进一帧**。持久区域是靠 `_tick_spell_zones` 每帧挂上去的，
施法完直接查必然是空的。于是那条「走出圈就失去免疫」**恒真**
（因为它本来就从来没被挂上过），整条镜像对照什么都没证明。

修法：`_run(w2, 0.05)` 之后再断言。诱捕网（一次性）不需要这一步 ——
**这正是两种机制的区别本身**。

## 三、一次性施法 vs 持久区域

同一个 `kind: "ground_aoe"` 下藏着两种语义，用 `SPELLS[x].instant` 区分：

| | 持久区域（心灵风暴 / 黑暗虫群） | 一次性命中（诱捕网） |
|---|---|---|
| 存在形态 | 留在 `spell_zones` 里自己倒计时 | **不生成区域**，只有 0.35 秒的一圈光 |
| 效果来源 | 每帧重新判定「谁在圈里」再挂 | **施法那一瞬间**抓一遍，挂满时长 |
| 走出去 | 立刻失效 | **照样慢满 25 秒** |
| 后来进圈 | 会中招 | **完全不受影响** |

⚠️ 把诱捕网做成持久区域的话，它变成「25 秒内谁进圈谁变慢」——
比原作强得多，而且和「移速减半持续 25 秒」这条数值设计对不上。

⚠️ **`_apply_instant_aoe` 用线性扫 `units`，不用 `query_units_near()`**：
哈希网格 `_hash` 只在 `step()` 开头重建，而**玩家指令是在 `step()` 之外进来的**
（输入事件 → `cmd_ability`）。用哈希网格的话，测试里更致命 ——
手工摆好单位直接调 `cmd_ability`，哈希还是空的，**一个单位都抓不到、而且不报错**。

## 四、诱捕网数值（照星际 1）

| 项 | 值 | 备注 |
|---|---|---|
| 能量 | 75 | 虫后满能量 200 → 只够放两次 |
| 施法距离 | 200 | |
| 区域半径 | 80 | |
| 持续 | 25 秒 | |
| 移速 | **×0.5** | |
| 武器冷却 | **×1.25** | 射速降约 1/5 —— **最容易漏的一条** |
| 影响 | `affects: "all"` | **敌我不分，且对空也有效** |

**为什么敌我不分不算过强**：它**不造成任何伤害**，误伤代价只是
「自己也慢了」。和心灵风暴的「打死自己人」不是一个量级。
测试里有一条专门断言「整段时长内敌我双方一点血都没掉」。

**科技链门槛**：虫后巢穴 `requires: "spire"`，不是 `"hive"`。
⚠️ 虫族的 `hive` 是**起始建筑**（`FACTIONS.zerg.start_buildings`），
写 `requires: "hive"` 等于**零门槛** —— 虫后开局就能造。
挂在尖塔下面和蝎子同一层，200/150 的尖塔是真代价。

⚠️ `BUILD_MENU` 同时驱动玩家建造菜单（`Main._draw_build_menu`）和
AI 建造顺序（`World._ai_produce`）。新建筑不进 `BUILD_MENU` =
玩家看不见、AI 也不会造 = **永远见不到的死内容**，而且不报错。

## 五、AI 落点判据：净收益，不是零容忍

| | 心灵风暴 | 诱捕网 |
|---|---|---|
| 判据 | 圈里**一个自己人都不能有** | **净收益 = 抓到的敌人 − 被牵连的自己人 ≥ 2** |
| 理由 | **会打死自己人**，不存在「划算」 | **不造成伤害**，3 敌 1 友仍然是赚的 |

套用风暴那条零容忍判据的话，两军一接触它就永远不放了 ——
而那时恰恰最该放。这是「同一个 `kind` 的两个法术，判据必须分开写」的具体例子。

阳性对照 `C14`（改成零容忍 → 「圈里有一个自己人时仍然放」那条红）、
`C16`（改成按阵营过滤 → 「敌我不分」那条红）。

## 六、造型：旋转不变性

⚠️★**单位贴图会被旋转**（朝向 `facing`），所以「画得竖一点 / 横一点」
**不能**用来区分单位 —— 竖着画的东西转 90° 就变成横的。
只有**旋转不变的轮廓特征**才算数。

- 虫后的特征：「一个大肚子 + **三颗排成一线的卵** + 头顶一根长角」。
- 刻意避开：不做「圆滚滚 + 一圈环」（那是**科学球**，两个都是零攻击力的
  空中支援单位，认错代价最直接：以为虫后能放辐照）、
  不做「一对尖翼」（那是**飞龙**；虫后的翼做成短而钝、半透明，不参与主轮廓）。
- 虫后巢穴主轮廓用**六边形** —— 但 `_bg_zerg` 给**所有**虫族建筑画了同一个
  「14 根尖刺的圆环底盘」，外轮廓完全一样，能区分的只有半径 36 以内的内芯。
  所以本轮新增了一张**同族建筑对照图** `26_zoom_zerg_buildings`
  （7 个虫族建筑 × 3 倍放大）—— 1 倍缩放的 `21_sheet_buildings` 里
  内芯只有二三十像素，撞车了根本看不出来。

## 九、接下来的方案（按「不做就会一直悬着」排序）

1. **真机验证** —— 从 M4c 悬到现在，两台真设备从没对打过一局。
   M5 又往协议里加了 `energy` + 效果列表 + 法术区域（v2），
   客户端不跑 `step()` 的那条路只有真机能验。
2. **法术对抗的平衡测试** —— `bal` 模式目前不含法术；
   诱捕网（降输出 20%）和心灵风暴（AOE）对三族胜率的影响还没测过。
3. **法术深度** —— `slow` 现在有产出方了，下一个自然是
   **瘟疫（Plague，按百分比掉血到 1 点）** 和 **冰冻（Stasis）**；
   前者能复用 dot 管线但需要「不能致死」的新语义。
